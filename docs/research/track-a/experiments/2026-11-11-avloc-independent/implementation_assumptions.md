# Implementation assumptions and HSSD adaptations

The following are decisions of this independent implementation, not asserted author details.

- Six circular microphones of radius5cm replace binaural HRTF sensors.18 spectrogram channels replace4. Adjacent pairs form a closed6-pair ring. Existing array orientation is canonicalized offline using the recorded sensor/pose contract; inference accepts body-frame waveforms, not GT pose.
- Source RGB contract is640×480,HFOV106.2602°, matching the paper's rounded106°. Positive body ray index follows increasing HSSD logical yaw; FoV indices31…35,0…5. Test-derived coordinate corrections are prohibited.
- Chirp is unit-amplitude cosine-phase logarithmic sweep. Paper gives frequency/time but not amplitude, phase, STFT window family, centering or log floor. Chosen Hann64, centered reflect padding, natural log(max(magnitude,1e−6)), no per-example amplitude normalization. Preserve direct path; do not inherit the old103-sample gate or32×32 feature pooling. Existing short RIR tails are zero-padded and must be quantified in the asset audit.
- Learned separable row/column positional embeddings; GELU, pre-layer normalization,FFN512,dropout0.1; prediction linear heads with softplus distances+1e−4 and scales+1e−3. Router hidden width16 and raw scale input. None of these omitted hyperparameters is claimed as an author design.
- Visual ray seeds use vertical-mean refined token columns and perspective angle sampling. No novel visual backbone is substituted. ImageNet ResNet50 weights use torchvision V2 (paper does not name a release); audio ResNet18 is initialized randomly.
- The interaction-disabled control uses the exact same joint-expert parameters in two isolated modality passes, followed by uniform moment fusion. It has matched parameters but different compute; report that difference. Unimodal predictions cannot access the other modality.
- Frozen effective batch32, AdamW weight decay0.01,AMP with finite-gradient checks. These values are assumptions; max100epochs/patience20/lr schedule/checkpoint-L1 follow AppendixB. Physical batch8 with four accumulation steps; final partial group is weighted by actual samples. Deterministic CUDA and paired initialization/augmentation are checked before production training.
- Paper AppendixC requests visual corruption probabilities, audio masking/ambient noise and joint horizontal reflection. Implemented: degradation probability.5; conditional brightness.6, Gaussian read noise.6, blackout.3, motion blur.3. Severity endpoints (assumed): brightness multiplier1−.95s, noise std.2s, rectangle area≤.75s, blur odd kernel1–31. Audio two time/two frequency masks width0–12 with probability.7; ambient probability.5, equally Gaussian or ESC50, paper SNR list. Reflection probability.5. ESC50 pinned commit33c8ce9eb2cf0b1c2f8bcf322eb349b6be34dbb6; local CC BY-NC3.0 research use, attribution retained.40 training/10 held categories are disjoint; held set includes five paper examples plus five deterministic hash-selected categories, not a claimed author split. ESC excerpts are shared across microphones; Gaussian noise is independent. This spatial noise model is an assumption. No audio data is uploaded.
- Test-family rule uses scene prefix before underscore:3 Train excluded. An additional1 Train shares a Val source family, leaving112 Train and19 Val before integrity filtering. This conservative exclusion is a leakage control, not a performance choice. Full near-duplicate geometry exclusion is not yet proven.
- Val19 is reused development with historical teacher/research exposure. Temperature fitting/correlation validation must use scene-grouped held-development folds rather than reporting the fitting subset as independent calibration. Test17 not used until explicit final freeze.
- Geometry targets use exact first blocked binary-pixel boundary DDA, with no10m cap; all131 scenes have bounded finite targets.19 Val geometry banks at20cm and10cm are complete. Primary20cm XY coordinates match historical bank schedule metadata exactly within1e−7, using6cm clearance. Metadata is a comparison check, not acoustic model input. Pose scoring/normalization evaluation remains pending.
