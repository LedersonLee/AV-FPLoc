# 검증셋 융합 개선을 재현했습니다

- **최종 후보는 강한 B2 기준보다 R@1m +1.659%p, 위치·방향 동시 성공률 +1.587%p를 기록했습니다.** 두 seed에서 개선됐고, seed 평균으로 검증 8개 장면 모두 동시 성공률이 올랐습니다.
- 이전 로그를 검토한 뒤 더 강한 기준을 재현했습니다. 새 학습형 선택기 3종이 실패하자 후보 공간의 국소 지지도로 방향을 바꿨고, 발견한 정밀도 손실까지 후속 실험으로 보완했습니다. 첫 보고서나 실험 batch를 종료 조건으로 삼지 않았습니다.
- **이번 성과는 학습형 adaptive gate의 개선이 아닙니다.** 모달리티 가중치를 유지한 채, 주변 후보의 지지도로 영역을 고르고 그 안에서 원래 융합 점수가 가장 높은 위치를 선택하는 결정 방식의 개선입니다.

## 같은 조건에서 비교한 결과

- 주 비교에서는 query ID, GT, 후보 위치·방향, checkpoint, 시각·음향 특징, 가중치와 평가 함수를 모두 고정했습니다. 새 branch 학습이나 checkpoint 수정은 없었습니다.
- 기준과 최종 방법 모두 `.85 × visual + .15 × acoustic`을 사용합니다. 음향을 전역적으로 약화하거나 끈 결과가 아닙니다.
- Scene macro도 개선됐습니다. R@1m은 72.194→73.918%, 동시 성공률은 70.609→72.249%입니다. XY 오차 중앙값은 0.2236m로 같고, p95는 11.769→11.417m입니다. Yaw 중앙값은 5°로 같습니다.
- 최근 CNN cross-attention의 저장 예측을 같은 Val8·지표로 재측정한 동시 성공률은 70.788%입니다. 최종 후보는 이 참고 기준도 넘었습니다. 다만 이 비교는 학습 구조가 다르므로 새로운 matched-training 실험이라고 부르지 않습니다.

## 불확실성과 시각 성공 보존

- 최종 후보의 R@1m 개선은 **+1.659%p [1.002, 2.341]**, 동시 성공률 개선은 **+1.587%p [1.016, 2.214]**입니다. 구간은 seed를 query 안에서 평균한 뒤 8개 scene를 10,000회 재표집한 기술적 95% 구간입니다.
- 두 seed의 전체 동시 성공률 개선은 각각 +1.504/+1.671%p입니다. seed 평균의 장면별 개선 범위는 +0.368~+2.917%p입니다.
- R@0.1m은 국소 지지도만 썼을 때의 손실을 정밀화로 회복했습니다. 최종 기준 대비 +0.143%p의 구간은 [-0.087, +0.400]으로 0을 포함하므로, 미세 정밀도 개선 자체를 확정하지 않습니다.
- 최종 방법은 기준 대비 평균 166.5개를 복구하고 100개를 악화시켜, seed당 순 66.5개를 더 성공시켰습니다.
- **시각 성공을 모든 장면에서 보존한다는 보장은 없습니다.** 시각 단독 성공 구간의 조건부 성공률 차이는 +0.096%p, 구간은 [-0.595, +0.629]입니다. 전체 평균은 나빠지지 않았지만 일부 장면에는 퇴행이 있습니다. seed42의 시각 성공 훼손은 145→146, seed43은 154→149였습니다.
- 구간은 작은 재사용 개발셋에 조건부인 기술 통계입니다. 다중 탐색을 보정한 유의성 검정이나 엄격한 비열등성 검정, 독립 Test 일반화 증거가 아닙니다. [장면별 결과와 위험](artifacts.json) (외부 산출물: `final_analysis.json`)

## 메커니즘을 구분한 대조 실험

- 같은 설정에서 XY 지지도만 쓰면 동시 성공률 72.375%, yaw 지지도만 쓰면 70.847%, 함께 쓰면 72.780%였습니다. 공간 지지도가 주요 효과이며, 방향 평활만으로 개선을 설명하기 어렵습니다.
- 이웃 후보 수로 나눈 대조도 72.601%로 기준보다 높았습니다. 단순히 후보가 많은 곳을 선호하는 효과만으로 전체 개선을 설명하기 어렵습니다.
- 최종 방식에서 음향 관측을 같은 장면의 다른 관측과 바꾸면 **30.418%**로 하락했습니다. 최종 알고리즘을 시각 단독에 적용한 결과는 **49.905%**, 원래 시각은 49.809%였습니다. 올바르게 대응된 음향 정보가 여전히 필요합니다.
- 두 단독 MAP가 모두 실패한 구간의 성공률은 **41.976→45.015%**, 시각 실패·음향 성공 구간은 **75.873→79.039%**로 올랐습니다. 둘 다 단독으로 성공한 구간은 98.207→98.051%로 소폭 떨어졌습니다. [하위집단 분해](archive/failure_diagnosis.md)
- 이 개입들은 후보 점수의 공간적 구조에 관한 설명을 지지합니다. 가구 반사의 물리적 원인이나 학습된 신뢰도 선택의 성공을 입증한 것은 아닙니다.

## 실패한 실험과 calibration 결과

- 강한 기준의 Val3 seed42 동시 성공률은 79.519%였습니다. 선형 성공위험 모델은 79.225%, 작은 트리는 79.401%, 기준 대비 이득 회귀는 78.756%였습니다. Train에서의 개선이 Val로 전이되지 않아 세 방법을 채택하지 않았습니다.
- 국소 지지도는 같은 진단 온도에서 성공영역 NLL을 1.465→1.421로 개선했지만, nearest-GT NLL은 5.471→5.763, ECE는 0.104→0.115로 악화시켰습니다. 정확도 개선을 확률 calibration 개선으로 해석하지 않습니다.
- 위 posterior 진단은 support field에 관한 것이며, 정밀화한 최종 출력의 새 calibrated posterior가 아닙니다.
- 모든 시도와 부정적 결과는 [실험 로그](artifacts.json) (외부 산출물: `experiment_log.csv`), [반복별 5줄 기록](archive/iterations.md), [가설 등록부](archive/hypothesis_register.md)에 보존했습니다. 실행 전 발견한 문법 오류도 [실행 기록](archive/execution_events.md)에 남겼습니다.

## 재현과 산출물

- 별도 추론 모듈: [inference.py](artifacts.json) (외부 산출물: `inference.py`), [고정 설정](artifacts.json) (외부 산출물: `inference_config.json`). GT나 scene ID를 입력받지 않습니다. 기존 baseline 코드와 체크포인트는 보존했습니다.
- B2 baseline의 full-bank 예측을 역사적 저장 index와 대조했습니다. 독립 추론 모듈은 16개 scene·seed 조합에서 선택한 320개 query 모두 최종 결과와 정확히 일치했습니다. 모든 8,380개 측정은 저장소 평가 함수로 다시 검증했습니다.
- Circular yaw 일관성, 음향 weight=0 대조, 잘못된 입력 거부도 통과했습니다. [검증 기록](artifacts.json) (외부 산출물: `inference_verification.json`)
- CPU decoder 시간은 중앙 1.19ms, p95 2.25ms였습니다. 이웃 행렬을 미리 만든 상태이며 encoder·FP matching·행렬 생성 시간을 포함하지 않습니다.
- 기록된 실행 단계의 process wall time 합계는 약 607초입니다. 병렬 실행이 겹치므로 전체 경과시간이나 실제 GPU 연산시간으로 해석하면 안 됩니다. 새 branch 학습은 없었고 작은 선택기 3종에 대해 총 15 fits를 수행했습니다.
- 실행당 CPU4/RAM8GB, PyTorch GPU allocator 45% cap을 사용했습니다. 실제 peak 메모리는 측정하지 않았습니다. 로컬 자원 자유 사용 승인을 받았으며 유료 자원·외부 업로드·새 데이터 생성은 없었습니다.

## 남은 한계

- Val8은 과거에도 개발에 사용된 장면입니다. support 후보는 Val3 이후 고정해 추가 Val5와 seed43에서 확인했습니다. refinement는 그 결과의 정밀도 손실을 본 뒤 제안하고 Train에서 검증했으므로, 이후 Val8은 재사용 확인입니다. **Test 파일은 열지 않았습니다.**
- 이전 v1과 package evaluator의 엄격한 ≤1m/30° 정의를 유지했습니다. 과거 보고서의 1e-6 tolerance와 단 한 관측의 경계가 달라, 역사적 B2 71.026%가 여기서는 71.014%입니다. 모든 방법에 같은 정의를 적용했습니다. [경계 감사](artifacts.json) (외부 산출물: `threshold_boundary_audit.json`)
- Euclidean 0.4m 이웃은 벽의 연결성을 따로 검사하지 않습니다. 현재 후보 집합과 Euclidean localization 지표에 대한 개선입니다.
- Furnished/unfurnished 동일 pose의 counterfactual이 없어 가구 mismatch의 인과 효과는 검증하지 않았습니다. 미관측 장면, 센서 노이즈, 실제 환경 일반화와 학습형 adaptive fusion 자체는 열린 연구 문제입니다.
