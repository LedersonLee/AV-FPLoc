가중치 그룹 구분력이 실제 Localization 개선으로 이어지는가?

Train12 / Val3 · 6,387 / 1,704쿼리 · 동일 scalar MLP · 입력만 바꾼16회 학습 · Test 미사용

이전 그룹 분류의 Balanced accuracy가 아니라 실제 dense MAP localization을 평가합니다. Val이 checkpoint를 선택하므로 독립 Test 성능이나 확정적 개선으로 해석하면 안 됩니다. Val-best와 epoch40 Last, 두 seed를 모두 공개합니다.

1. 앞선 표의 정확한 해석

  • 성공 없음927개: 현재 frozen 점수와 scalar fusion, .2m/10° 후보에서 위치1m·yaw30°를 동시에 만족하는 가중치가 없음. scene 자체의 원천적 불가능을 뜻하지 않음.
  • 고정.1 성공4,493개 = L+M의917개 + L+M+H의3,576개.
  • H만 성공군의.225는 선택된 w가 아니라 성공 구간 총폭의 중앙값.
  • L+M+H는 각 범위에 성공하는 값이 있다는 뜻. 두 endpoint인 Vision-only(w=0)와 Acoustic-only(w=1)의 성공을 보장하지 않음.

2. 입력의 내용과 선정 근거

58개는 기존14 + 이전에 만든 가공44입니다. 새 주변영역 반응15개는 이번 후속 분석에서 추가했습니다. 이번 localization 실험에는 탐색했던165개 전체나 RGB 명암 특징을 넣지 않았습니다.

동일 구조: 입력 → 32 → 16 → scalar logit → sigmoid → acoustic w. Fusion 점수는 (1−w)V+wA이며 encoder는 고정입니다. 입력14/29/58/73개에 따라 첫 층 파라미터 수만 달라집니다.

3. 실제 Localization 결과

Recall·yaw 비율 단위는 %. Repair/Harm은 고정 acoustic w=.1 대비 쿼리 수입니다. Joint는 위치1m 및 yaw30°. ep0은 가중치.1로 초기화된 미학습 상태입니다. Val-best는 scene-macro R@1m → macro Joint → 해당 loss 순으로 선택했습니다. 따라서 일부 행의 R@.1m 또는 Joint가 개선되지 않을 수 있습니다.

평균 w 고정 대조는 가공58·logit·seed42·Val-best 모델이 Train에 출력한 평균(약.2296)을 모든 쿼리에 공통 적용합니다. 동일 checkpoint에 조건부인 비교이며, 독립적으로 선택된 최적 상수라는 뜻은 아닙니다.

가중치 변경의 이득과 위험

가공58·logit·seed42·Val-best를 기준으로 합니다. GT 안전 반경은 w=.1이 들어 있는 성공 구간의 가까운 끝까지 거리로, 사후 진단에만 사용했습니다. 이 모델의 Val 출력은 모두.1보다 높았습니다. 따라서 낮춰야 복구되는 쿼리를 해결했다고 볼 수 없습니다. Harm30개 중27개는 L+M군입니다.

4. 학습 곡선

40epoch·batch16·AdamW lr=.001·weight decay0·gradient clip1, scheduler/조기 종료 없음. 기존과 동일한 target·loss·scene balancing을 유지하고, 정규화는 Train 전체에서만 계산했습니다. 작은 MLP와 캐시된 특징을 사용하므로 RIR/encoder 학습보다 훨씬 빠릅니다.
