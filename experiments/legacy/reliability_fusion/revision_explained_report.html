가중치의 의미

현재 query q마다 acoustic 가중치 wA(q) 한 개와 vision 가중치 wV(q)=1−wA(q)를 사용합니다. 같은 query의 모든 위치·yaw 후보에는 같은 가중치가 적용됩니다. 후보별 가중치나 위치/yaw별 별도 가중치가 아닙니다. 다음 query가 들어오면 adaptive 모델은 다른 값을 출력할 수 있지만, 상수 모델은 모든 query에 동일한 값을 사용합니다.

s(q,pose)=(1−wA(q))·zV(q,pose)+wA(q)·zA(q,pose). 각 modality 점수는 query의 전체 후보 bank에서 z-score 정규화합니다.

Best = val scene-macro R@1m → 공동 성공률 순으로 선택한 checkpoint. Last = 학습이 종료된 마지막 checkpoint. Best ep0은 학습 전 초기값이며, 학습이 실행되지 않았다는 뜻은 아닙니다. 이후 checkpoint가 초기 성능을 넘지 못한 것입니다.

7개 학습 조건 · Best와 Last를 구분

동일 14개 입력·작은 MLP·optimizer·seed를 사용합니다. 공통 상수 조건만 query 입력을 사용하지 않고 scalar 한 개를 학습합니다. 온도 T는 fusion loss 온도이며 acoustic contrastive 학습의 τ=0.07과 다릅니다. NLL(T)=logsumexp(s/T)−E_GT[s]/T. 낮은 T는 분포를 날카롭게 만들지만, 고정된 w에서 MAP pose 순위를 바꾸지는 않습니다.

조건별 Test Best 전체 지표 — 초기값이 같은 경우 수치가 같은 이유

아래 행은 조건별 Best만 표시합니다. Query별 모델의 Best가 모두 epoch0이면 같은 초기 w=0.1에서 같은 pose를 출력하므로 수치가 동일합니다. 실제 학습 후 차이는 위 Last 열에서 확인할 수 있습니다. Test Last는 frozen checkpoint의 사후 진단이며 모델 선택에 사용하지 않았습니다.

GT oracle · 실제 모델과 분리된 사후 진단

Oracle은 GT를 사용하므로 실제 추론에 사용할 수 없습니다. Query별 w를 0, 0.05, …, 1의 21개 값에서 고릅니다. 학습·설정·checkpoint 선택은 변경하지 않았습니다. 성공 oracle은 해당 성공 기준에 대해서만 이 격자에서의 ceiling입니다. 연속 가중치 전체의 상한이나 모든 지표의 상한은 아닙니다. GT NLL oracle은 NLL 최소값을 고를 뿐, 위치/yaw 성공률의 상한이 아닙니다. 동일 목적값이면 w=0.5에 가까운 값을 선택합니다.
