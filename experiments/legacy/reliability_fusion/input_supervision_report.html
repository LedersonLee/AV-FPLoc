1. 가까운 14개 입력 — 성공 가능한 가중치도 가까운가?

14개 입력은 Train 평균·표준편차로 정규화한 뒤 RMS L2 거리를 계산했습니다. Train 쿼리는 자기 scene 전체를 제외하고 다른 Train scene에서 이웃을 찾습니다. Val의 이웃도 Train에서만 찾습니다. 같은 위치의 다른 yaw를 암기하는 비교를 방지했습니다.

완전 충돌: 두 쿼리 모두 연속 성공 구간이 있지만 교집합이 없음. 선택 target 충돌: 기존 회귀가 택한 MAP-winner 구간끼리 겹치지 않음. 이 두 지표는 분모가 다르므로 직접 빼지 마세요. Random은 각 쿼리마다 다른 Train scene에서 20개를 추출한 참고 비교입니다.

2. 성공 구간과 단일 회귀 정답의 차이

이미 w=0.1에서 성공한 쿼리도 해당 winner 구간의 중간값을 정답으로 회귀시켰습니다. 구간 내 값들은 localization 기준으로 모두 성공인데도 특정 숫자 하나를 맞추도록 했다는 뜻입니다. 이것은 불필요한 회귀 부담의 근거이지, 실패 원인 전체를 단독으로 증명하는 결과는 아닙니다.

입력을 아예 쓰지 않은 회귀 목표 대조

3. 가공 입력이 Repair / Harm을 구별하는가?

고정 w=0.1에서 w=0.2 또는 0.5로 바꿨을 때 실패→성공은 Repair, 성공→실패는 Harm입니다. 성공 여부가 그대로인 쿼리는 이 이진 구분 과제에서 제외했습니다. 따라서 아래 AUROC는 전체 Recall이 아닙니다. 모델은 Train으로만 학습하고, hyperparameter와 threshold(0.5)는 Val에서 조절하지 않았습니다.

OOF = Train을 scene 단위 4-fold로 분리. AUROC 0.5는 무작위 순위 수준입니다. Δ AUROC는 같은 진단 모델의 기존14 입력 대비 값. CI는 Val 각 scene 안에서 물리 pose별로 yaw들을 묶어 1,000회 bootstrap한 조건부 구간입니다. 새로운 scene으로의 일반화를 보증하지 않으며 다중 비교 보정은 하지 않았습니다.
